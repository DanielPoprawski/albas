# Package 09 — Mobile Dashboard

**Design reference:** `designs/Albas Mobile Dashboard.dc.html`

**Wave 3 — after the Desktop Dashboard lands.**

## Files you own
The mobile branch of `src/components/HomeView.tsx`, `src/useMedia.ts`, and mobile styles.

## Scope
Single-column mobile dashboard with **bottom tabs: Today | Calendar | All**. No desktop sidebar, no bottom taskbar — mobile uses native-style navigation.

Reuse the tokens and the card/pill/checkbox primitives from packages 00 and 02; do not fork their styling. Hit targets are **44px minimum**.

## Done when
The mobile view matches the design file at 390px width and the media-query switch between mobile and desktop is clean.
